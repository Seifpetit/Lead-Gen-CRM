# Demo GIFs

The main README has commented-out slots for these. Record each one, save it here with the file
name shown, then delete the `<!--` and `-->` lines around its slot in the root `README.md`.

Use only fake or sample data. No real company names, phone numbers or emails on screen.
Keep each GIF under about 8 MB and 10 seconds, at roughly 1280 x 720.
